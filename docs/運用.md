# 運用のしかた

## 1. 毎日の自動更新

毎朝 日本時間 6:43 ごろ、ワークフロー「毎日の更新」が動きます。

1. `data/config.json` の `sessions` に書いた国会の議案一覧を、参議院のサイトで確かめる
2. 両院で可決・承認されたもので、まだ載せていないものを `data/pending/` に保存する
3. AIが記事を書き、機械とAIで確かめる
4. 通ったものを `data/feed.json` に入れ、チェックしてから公開する
5. 通らなかったものは公開せず、Issue（ラベル「要確認」）で知らせる

何も変わらなかった日は、何もしません。

### 新しい国会が始まったとき

`data/config.json` の `sessions` に回次を足します（例：`[222, 223]`）。
閉会して全件を載せ終えた回次は消してかまいません（消さなくても、載せ済みのものは二重に載りません）。
`data/feed.json` の `sessions`（会期の一覧）にも、その国会を足してください。

## 2. 手で更新するとき

GitHub の「Actions」→「毎日の更新」→「Run workflow」。
回次を入れると、その国会だけを確かめます（空なら `config.json` のとおり）。

## 3. 最初の設定（1回だけ）

### APIキー

「Settings」→「Secrets and variables」→「Actions」→「Secrets」に2つ登録します。

| 名前 | 中身 |
|---|---|
| `ANTHROPIC_API_KEY` | 書く担当（Anthropic）のAPIキー |
| `OPENAI_API_KEY` | 確かめる担当（OpenAI）のAPIキー |

キーがない間は、記事を書かずに下書きのまま待ちます（勝手に公開されることはありません）。

### モデル名（任意）

同じ画面の「Variables」に `WRITER_MODEL`・`CHECKER_MODEL` を登録すると、使うモデルを変えられます。
登録しないときは、ワークフローに書いた既定のモデルを使います。使ったモデル名は、記事ごとの記録（`data/logs/`）に残ります。

### 費用の目安

1件あたり、書く・確かめる・書き直しを合わせて数万トークン程度です。
2026年の第221回国会（約5か月）で載せたのは98件なので、年間でも数百件ほどです。
各社の料金表で、使うモデルの単価をかけて確かめてください。

### GitHub Pages

「Settings」→「Pages」→「Build and deployment」の Source を「GitHub Actions」にします。

## 4. 公開されなかった記事（Issue「要確認」）

理由は2つあります。

- **議案要旨がまだ出ていない**：参議院のサイトに要旨が載ると、次の日以降に自動で書き直します。
  急ぐときは、`data/pending/<名前>.json` の `status` を `fetched` に戻すと、次の更新でもう一度試します。
- **3回書き直してもチェックに通らなかった**：`data/logs/<名前>.json` に、どこが問題だったかが残っています。
  人が記事を直すときは、`data/feed.json` に直接書き足し、下書きのファイルを消してください。

どちらの場合も、片づいたら Issue を閉じます。

## 5. 間違いを直すとき（ルールT-2）

1. Issue「訂正の依頼」で受け付ける
2. 出典と照らし合わせて確かめる
3. `data/` のファイルを直し、プルリクエストを作る（チェックが自動で動きます）
4. 何をいつどう直したかを、その記事の `corrections` に残す
   例：`"corrections": [{"date": "2026-11-05", "text": "施行日を「令和9年4月1日」に訂正（元は4月10日）。"}]`
5. 取り込むと、自動で公開されます

## 6. ルールを変えるとき（ルールT-1）

1. Issue「ルール変更の提案」で、変更案と理由を公開する
2. しばらく意見を待ってから、`data/rules.json` を直すプルリクエストを作る
3. `version` を上げ、`history` に「いつ・何を・なぜ」を足す
4. AIの書き方に関わるときは、`prompts/` の指示文も同じプルリクエストで直す

## 7. 手元で試すとき

```sh
python pipeline/validate.py            # 公開前のチェック
python pipeline/update_laws.py --sessions 222
python -m http.server 8000             # http://localhost:8000 でサイトを見る
```
