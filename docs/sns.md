# SNS の投稿（ルール D-17）

## 何を出すか
- 記事の知らせ：新しく公開した「国会で決まったこと」の記事（pipeline/social.py）。
- データの数字のポスト：毎日 12:03 と 21:03（日本時間）に1本ずつ（pipeline/social_facts.py）。
  決まった型にこのサイトのデータの数字を入れた文と、同じ数字のグラフ。AIは使わない。
  - 1文目：数字の答え。2文目：数え方と出どころ。最後：このサイトのページ。ハッシュタグなし。
  - 個人の名前は入れない。政党・会派どうしを比べる型は作らない。
  - 一番長く出していない型から順に出す。月曜はパブリックコメントの型を先に。数字が同じポストは30日出さない。
- 確かめ方：`python pipeline/social_facts.py`（候補を全部 out/social/ に書き出す）、`python pipeline/social.py --facts --dry-run`（次に出す1本）。

## 型を決めるときに参考にしたこと（2026-11-06。@edinetdb 1,044件と @seisakudb 215件のポストを読んだ）
- @edinetdb の毎日のデータのポストは「〇〇な上場企業は△社でした。全体の□%です」＋数え方＋グラフ。12:03・21:03・8:00 の予約投稿。
- 画像つきは文字だけより、いいねの真ん中の値が約3倍。ハッシュタグはほぼ使っていない。
- @seisakudb（政策DB）で伸びたのは「よく語られるテーマ」と「お金が動くテーマ」のように2つをくらべたもの。1件の事実だけのポストはほぼ伸びない。
- いいねが多かったのは、AIにつなぐ使い方、集めたデータの量、季節の話題と組み合わせた使い方。これは型にせず、人が一度だけ出す。
- ニュースへの引用コメントは伸びるが、意見になりやすいので、このサイトでは自動ではしない。
